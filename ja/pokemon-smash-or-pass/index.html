    しくみ

    ポケモン smash or pass の遊び方

    smash or pass ってどんなゲーム？

    smash or pass は、配信やショート動画で広まった判定ゲームです。ポケモンが1匹出てくるので、「アリ（もらう）」か「ナシ（いらない）」を決めるだけ。楽しいのは、テンポよく判定していくところ、思わぬポケモンが出てくるところ、そして自分の好みが数字に出てくるところです。このジェネレーターは、1匹・2ボタン・次へ、という定番の流れはそのままに、連続記録とシェアできる判定スコアを足しました。ポケモン版 smash or pass だと思ってください。ボタンもルールも同じで、顔ぶれが全国図鑑まるごと、というだけです。

    3タップで遊べる

    スタートを押すと最初のポケモンが出ます。名前、タイプタグ、世代バッジを見てから、タップ: アリか ナシ — キーボードの S と P キーを使えばもっと速く遊べます。次のポケモンはすぐ出て、カウンターがアリ率・連続記録・これまでの判定履歴を記録していきます。アカウントもインストールも不要、回数制限もありません。

    全ポケモン挑戦をやってみる

    じっくり遊ぶなら、全ポケモン挑戦がおすすめです。第1世代から第9世代までの1,025種とリージョンフォームを、全部判定してみてください。プールを一周するまで同じポケモンは出ません。最後のアリ率を友達と比べてもいいし、ひとつの地方だけに絞れば短時間で終わります。

    アリリストを作ろう

    「アリ」を押すたびに、好きなポケモンへの一票が積み上がります。遊ぶほどアリリストが伸びていくのを見てください。判定履歴パネルには、これまでの判定がイラスト付きで全部残るので、あとから自分の好みを振り返れます。ファンはこのリストで友達と言い合ったり、ティアリスト動画の準備をしたり、「どれくらい選り好みするか」の議論を決着させたりしています。

    配信やショート動画向け

    smash or pass は配信やショート動画とも相性ばつぐん。S / P のショートカットで判定を速いテンポに保てて、連続記録がドラマを作り、レアな色違いが出た瞬間はクリップ映えします。配信で視聴者に投票してもらいながら遊んでもいいし、録画してリアクションを投稿するのもアリです。

    このカードは、ポケモンのタイプ相性をその場で確かめられる計算機にもなります。データ表の下にあるタイプ相性の行を見れば、出たポケモンが何に弱く、何に抵抗でき、何を無効にするかがひと目でわかります。18タイプの相性表からその場で計算しているんです。「アリ」か「ナシ」を押す前に4倍弱点やきれいな無効を見つけられるので、遊びながら対戦の練習にもなります。

    ハウスルールと自分流

    楽しいのは、自分流のルールを考えること。御三家は禁止、判定するのは 進化前 ポケモンだけ、1判定ごとに5秒タイマー、みんなで投票してから押す——どれも盛り上がります。ヌズロックを遊ぶ人は、これをフィルターに使っています。アリにしたポケモンは必ずチームに入れる、と決めて、 ヌズロック編成 で、ルール一式が確認できます。

    どこでも遊べる

    smash or pass は、どのブラウザでも動きます。登録もインストールも待ち時間もありません。休憩中にスマホで判定してもいいし、パーティーで大画面に映すのも楽しいです。スタートをもう一度押せば、ランダム順も連続記録もリセット。判定より「作る」ほうが好きなら、 random Pokemon generator でチームを丸ごと組めます。それか ポケモンルーレット を回して運に任せるのもアリ。判定に飽きたら、シルエットの後ろに隠れたポケモンの名前を当ててみてください。 このポケモンだあれ？ クイズ。アリにしたポケモンがチーム入りするなら、性格は ポケモン性格表 で、種族値に合う性格を選べます。

    全国図鑑まるごと判定チャレンジ

    コンプ勢向けの遊び方もあります。図鑑の全種を、1判定ずつ片付けていくんです。判定は1,025回。1判定3秒のペースなら、タップだけで約1時間。集中力の続く範囲で、何回かに分ければOKです。

    長く遊ぶと、数字が面白くなってきます。ずっと同じ方向に寄っていくリストは「その日の気分」、図鑑の真ん中あたりで行ったり来たりするリストは「好み」です。そして終わったときのシェアカードは、作者があなたひとりだけのランキングになります。

    判定スコアをシェア

    遊び終わったら、「判定をシェア」を押してください。「I smashed 23/30 Pokémon on Random Pokemon Generator — どれくらい好みにうるさい？」のようなサマリーが、友達がそのまま開いて遊べるリンク付きでコピーされます。Discord、Reddit、TikTok のコメント欄に貼ってみてください。

    ハウスルールで何度でも新鮮に

    判定ループは、自分ルールを足すほど長く楽しめます。伝説なしのドラフト、世代を固定した地方しばり、ドリームチームに入るポケモンだけアリにする——どれもアリです。これはゲーム設定パネルで調整できます。ランダム順と図鑑順の切り替え、判定したいタイプや地方へのチェック、伝説と幻をオフにして地に足のついた回にする、どれもここで。判定ボタンも自由自在で、クリックでもスワイプでも、S と P キーでも動きます。ひとりで判定しても、トレーナーでいっぱいの部屋でも同じ。議論が片付いたら、お気に入りを パーティ編成 に入れて、性格・技・道具までそろった本物の6匹チームに変えましょう。お気に入りにはカードを。 ポケモンカード作成 なら、アリにしたポケモンをオリジナルカードにできます。 トレーナーカード作成 なら、プロフィール用のトレーナーカードも作れます。ブログの新着は ポケモン smash or pass ティアリスト 。S ティアから D ティアまで、全ポケモンをランク付けした記事です。

    よくある質問

    ポケモン smash or pass よくある質問

    ポケモン smash or pass とは？

    smash or pass は、ランダムに出てきたポケモンを見て、「アリ（もらう）」か「ナシ（いらない）」を決めるバズゲームです。このジェネレーターなら、Gen 1-9 の1,025匹がワンクリックで判定でき、判定数・連続記録・アリ率もその場で記録されます。ある程度さばいたら、最終スコアと判定リストを友達にシェアできます。

    smash or pass の遊び方は？

    スタートを押すと、ポケモンが1匹配られます。カードを見て「アリ」か「ナシ」を選ぶだけ。S と P キーでも動きます。次の1匹はすぐ出て、連続記録・判定数・アリ率はどんどん更新されていきます。

    世代で絞り込めますか？

    はい。始める前に世代チップ（第1世代〜第9世代）をタップすれば、その地方のポケモンだけを判定できます。カントーだけ、パルデアだけ、もちろん全部でも。定番の第1世代しばり——最初の151匹で smash or pass——をやりたいなら、第1世代をタップしてスタートするだけです。

    全ポケモンのリストはありますか？

    はい。ゲームが使うのは、smash or pass 用の完全なリストです。Gen 1-9 の1,025匹にリージョンフォームを加えたもので、どのカードにも公式イラストとタイプが付いています。

    結果はシェアできますか？

    タップ1回で完了。シェアボタンを押すと、「I smashed 23/30 Pokemon on Random Pokemon Generator — どれくらい好みにうるさい？」のような判定サマリーがリンク付きでコピーされ、Reddit でも Discord でも SNS でもそのまま貼れます。

    色違いは出ますか？

    出るときは出ます。全体の約8%は、キラキラ光るイラストの色違いポケモン。アリにするかナシにするかは、お好みで。
