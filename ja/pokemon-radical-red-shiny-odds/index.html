ポケモン Radical Red の色違い確率

Radical Red は、土台になったカセットよりずっと色違い狩りに優しいROMハックです。バージョン4.1で公表されていた2つの確率がどちらも倍になり、通常の野生エンカウントは4,096分の2、つまり2,048分の1になりました。ひかるおまもりを持っていれば4,096分の6、683分の1まで上がります。下にある素のファイアレッドは8,192分の1なので、ブーストなしでも約4倍、おまもりを手に入れれば12倍の速さで狩れる計算です。ここからは、このハックが公表しているすべての確率、おまもりの入手方法、デックスナビが実際に何をしているのか、そして自分の狩りを計算するツールを紹介します。

計算機は Radical Red 専用です。ひかるおまもりを持っているならオンにしてください。カードには野生1回あたりの確率、色違い1体あたりの平均エンカウント数、その回数を自分のペースで消化したときの所要時間が出ます。デックスナビの連鎖はこのモデルの外側です。ハック側が倍率を公表しておらず、コミュニティの計測も互いに食い違っているので、下のセクションでは数字をでっち上げて計算機に放り込むのではなく、仕組みのほうを説明します。

基本確率は4,096分の2（2,048分の1）。ひかるおまもりは抽選を4回分追加して、同じエンカウントを4,096分の6（683分の1）にします。本編のおまもりが追加するのは2回分なので、それより大きな跳ね上がり方です。どちらの数字も、ハックのバージョン4.1の更新履歴に書かれています。

仕様

Radical Red での色違い狩りの仕組み

4.1のパッチで色違いのルールが組み直され、おまもりの入手方法もポケモン図鑑コンプリートの定番ルートではありません。何が変わったのか、ブーストがどこから来るのか、そして狩りを丸ごと飛ばす近道を1つ紹介します。

バージョン4.1で変わったこと

古いバージョンの Radical Red は本編の数字を使っていました。野生エンカウントが4,096分の1で、そこにおまもりの4,096分の3が乗る形です。4.1でどちらも倍になり、基本が4,096分の2、おまもり込みが4,096分の6になりました。同じパッチで色違いのグラフィックもおよそ115体ぶん描き直されています。これは見た目以上に効きます。以前のハックの色違いは、暗いドットの色相がわずかに動いただけのものが多く、この修正でまともな配色になった子がかなりいます。このハックで狩りをしていて、4.1より前の記事を読んでいるなら、書いてある確率は間違いです。

ひかるおまもりの入手方法

ヤマブキシティのナツメが渡してくれます。彼女は5人目のジムリーダーなので、ふつうに進めていれば本編と同じくらいの時期に手に入ります。コミュニティのガイドには2段階の手順として書かれています。まず3回勝ち、次に個体値が最大のポケモンを見せる。Minimal Grinding モードでは2つ目の条件が変わり、色違いなら何でも受け取ってもらえます。このモードは個体値を上げる手段を気前よく配るので、現実的な選択肢になります。ただしこれは更新履歴ではなくコミュニティの記録なので、条件の細かい言い回しはバージョンによって変わる可能性があります。

ゲームコーナーで色違いを買う

タマムシのゲームコーナーではポケモンをそのまま売っていて、色違いも棚に並びます。通常の価格は1匹100,000ポケドル、色違いは倍の200,000ポケドルです。品揃えは疑似伝説に寄っていて、ここが気にする理由になります。本来なら一晩を溶かすような種族の長い狩りを、丸ごと飛ばせるわけです。ネックは入店条件で、物語の途中でロケット団側につかないと店が開きません。別の道を選んだ旅では、そもそも買いに来られません。

無料のふしぎなおくりものコード

バージョン4.1で、色違い狙いの人向けのふしぎなおくりものが追加されました。2周目 ではポケモンセンターでジョーイさんに話しかけると受け取れます。コードは 色違い （実際の文字列は「Shiny」。Sだけ大文字で、ほかはすべて小文字です。小文字のsでは受け付けられません）。恒久的な確率変更ではなく、1回きりのプレゼントとして扱ってください。何とも重複せず、セーブデータをまたいで持ち越すこともできません。

仕様

デックスナビは Radical Red の色違い確率をどう変えるか

Radical Red の色違い狩りは楽だと言う人がいるなら、理由はデックスナビです。オメガルビー・アルファサファイアに入っていたのと同じ仕組みをファイアレッドのエンジンに移植したもので、種族ごとに2つのつまみがあります。

1つ目のつまみは サーチレベルです。種族ごとにカウンターがあり、その種族と出会い続けるほど上がって、上限は255。2つ目は 連鎖。同じ種族と出会い続けて途切れさせなければ、連鎖が100まで積み上がります。どちらも確率を下げますが、連鎖にはもうひとつ仕事があります。ゲームが行う色違い判定の回数そのものを増やすんです。長い連鎖はほんの少しの後押しではなく、何回分もの抽選を1回のエンカウントに束ねるものだと思ってください。

ややこしくなるのは計算のほうです。Radical Red の資料にはデックスナビの公式倍率が存在せず、出回っているコミュニティの数字も大きく食い違っています。634分の1あたりという主張もあれば、ほぼ1%きっかりという主張もあり、倍半分の開きがあります。これはどちらかが雑という話ではなく、計測ツールごとに追加抽選の扱いが違うからです。実用的に言えるのは、サーチレベルをカンストさせて連鎖を100まで伸ばした状態が、このハックで得られる最良の確率だということ。そして、そこで引用される具体的な分数は、解析で確定した定数ではなく推定値として扱うべきだということです。サファリゾーンのこともここで知っておきましょう。バージョン4.1でサファリゾーンは普通のエリアとして扱われるようになり、デックスナビが中でも動くようになりました。以前は動かなかったんです。

連鎖に入る前に、実務的な注意をひとつ。連鎖はルートではなく種族を数えるので、別のポケモンと不意にエンカウントすると簡単に切れます。切れたら最初からやり直しです。混ざった群れをかき分けずに狙える種族を選んでください。

実際の目安

Radical Red の色違い狩りはどれくらいかかる？

確率はチケットの値段のようなもので、この表は実際に何枚買うことになるかの話です。各行は公表された確率をエンカウント数に変換したもの。中央値は狩りの半分が終わっている地点、99%はほとんど誰もまだ回していない地点です。

あなたの色違い確率中央値（50%）99%の人がここまでに
2,048分の1（ふつうの野生）1,420回のエンカウント9,430回のエンカウント
683分の1（ひかるおまもりあり）473回のエンカウント3,142回のエンカウント
8,192分の1（素のファイアレッド、比較用）5,678回のエンカウント37,724回のエンカウント

エンカウントは1回ごとに独立した抽選なので、中央値を超えた狩りに「そろそろ来る」はありません。優しい683分の1でも、3,142回続けて出ないことは100回に1回起きます。上の計算機は、自分のペース（1時間あたりのエンカウント数）を時間の見積もりに変えてくれます。

よくある質問

ポケモン Radical Red の色違い確率についてよくある質問

Radical Red の色違い確率は？

通常の野生エンカウントが4,096分の2、つまり2,048分の1です。ひかるおまもりを持っていれば同じエンカウントが4,096分の6、683分の1になります。どちらもハックのバージョン4.1の更新履歴の数字で、以前のバージョンの倍になっています。

Radical Red でひかるおまもりはどう手に入れる？

ヤマブキジムのリーダー、ナツメからです。コミュニティのガイドでは2段階の手順で、3回勝ってから、個体値が最大のポケモンを見せるとされています。Minimal Grinding モードでは条件が変わり、色違いのポケモンなら何でもよくなります。

Radical Red でデックスナビは色違い確率を変える？

変わります。しかもゲーム内で一番大きな要素です。種族ごとにサーチレベルがあり、255まで上がります。そのうえで同じ種族を100回まで連鎖できます。どちらも確率を下げ、連鎖は1エンカウントあたりの色違い判定の回数自体を増やします。公式の倍率は公表されておらず、コミュニティの数字も食い違っているので、目にする具体的なデックスナビの数値は、解析で確定した事実ではなく推定として扱ってください。

Radical Red の色違いふしぎなおくりものコードは何をする？

ふしぎなおくりものはバージョン4.1で追加された、色違い狙いのための配布です。2周目 でポケモンセンターのジョーイさんに話しかけると受け取れます。コードは頭文字が大文字の Shiny。1セーブにつき1回のプレゼントで、恒久的な確率変更ではありません。

Radical Red で色違いのポケモンは買える？

買えます。タマムシのゲームコーナーです。通常のポケモンが1匹100,000ポケドル、色違いは倍の200,000ポケドル。品揃えは疑似伝説寄りで、店は物語の途中でロケット団側についた場合しか開きません。

2,048分の1は本編より良い？

かなり良いです。第6世代以降の本編は4,096分の1、Radical Red の土台である初代ファイアレッドは8,192分の1。つまり Radical Red の狩りは、ブーストなしでファイアレッドの4倍、ひかるおまもりを持てば12倍の速さになります。

公式作品と比べる

この 色違いの出現率 のページなら、全作品を横に並べて比べられます。作品を切り替えられる計算機つきです。 ソード・シールドの色違い確率 はダイマックスアドベンチャーのルートを扱っていて、 ポケモン ブリリアントダイヤモンド・シャイニングパールの色違い確率 は、デックスナビの連鎖に一番近い動きをするポケトレの連鎖を扱っています。

確率を狩りに変える

狙う相手が決まったら、 ランダム選出 が候補を1匹ずつ絞り込み、 パーティ編成 が、最後に光った1匹を軸にチームを組みます。狩りそのものを飛ばしたいなら、上の色違い生成ツールが1クリックで完成した色違いを出してくれます。
