ポケモンGO CP計算ツール

ポケモンを選び、こうげき・ぼうぎょ・HPの個体値を入れてレベルを動かすと、CPがすぐに更新されます。下のパネルにはレベル40・50の上限と、スーパーリーグ・ハイパーリーグで止めるべきレベルが出ます。

CPは決まっています。同じ種族・同じ個体値・同じレベルなら、いつでも同じ数字になります。ここに推測はなく、レベル50の欄も2020年に実装されたXLアメの倍率を使っています。

    CPはどう決まるか

    GOのポケモンはすべて、こうげき・ぼうぎょ・HP（スタミナ）の3つの種族値を持っています。個体値はそれぞれに0〜15を足し、レベルはCPMという倍率をかけます。ゲーム内では次の式で計算されています。

    CP = floor( (こうげき + 個体値) x √(ぼうぎょ + 個体値) x √(スタミナ + 個体値) x CPM2 / 10 )

    式のなかで、こうげきだけはそのまま足され、ぼうぎょとHPは平方根の中に入ります。だからCPは攻撃側に強く寄ります。ミュウツーを例にすると、個体値0/0/0のレベル40で3,697、15/15/15で4,178です。同じ種族・同じレベルで481の差、これが個体値の差です。

    CPにランダムな要素はありません。種族・個体値・レベルが分かれば、ゲームが表示する数字をそのまま出せます。アプリと同じ計算をしているからです。

    個体値がCPに与える影響

    個体値は思っているより効きません。図鑑全体で見ると、15/15/15は0/0/0と比べてCPがおよそ8〜10%上がるだけです。種族値が100〜300あるところに15を足しても、割合としては小さいからです。

    レベルのほうがはるかに効きます。同じミュウツーをレベル20から40に上げるとCPは2倍以上になりますが、個体値を0/0/0から15/15/15にしても数百しか変わりません。だからCPだけを見るなら、個体値の悪いレベル35が、個体値完璧なレベル20に勝ちます。

    個体値が勝敗を分けるのは、CP上限のある対戦（PvP）です。両方が上限に張り付くと、残るのは能力の配分だけになります。この場合、0/15/15のほうが15/15/15より強いことがよくあります。こうげきが低いぶん同じ上限でも高いレベルまで上げられ、耐久の差でミラーを制せるからです。

    レベルとCPM、そして2つの上限

    レベルは1から50まで0.5刻みで、それぞれに倍率があります。レベル1（CPM 0.094）からレベル40（0.7903）までが強化の大部分で、最後の10レベルで上乗せされるのは6%ほどです。XLアメはポケモンを別物にするのではなく、少し伸ばすものだと考えてください。

    知っておきたいルールが2つあります。なかよし度が最大のポケモンは、強化済みのレベルにさらに1レベル分が乗ります。天候ブーストで捕まえたポケモンは、通常より5レベル高い状態で手に入ります（レイドなら20ではなく25、野生なら30ではなく35）。

    フシギダネで見ると、個体値完璧のレベル40で1,115、レベル50で1,260です。種族は変わらず、倍率だけが変わるからです。

    進化でCPはどう変わるか

    進化すると、レベルと個体値はそのまま引き継がれ、種族値だけが入れ替わります。なので進化後のCPは「新しい種族を、いまのレベル・いまの個体値で計算した値」になります。3段進化だと大きく跳ね、2段進化だと控えめに見えるのはそのためです。

    リーグ上限と止めるべきレベル

    スーパーリーグは1,500、ハイパーリーグは2,500が上限です。なので強さは数字の大きさではなく、上限の下でどれだけ能力を詰め込めるかで決まります。個体値完璧なミュウツーはレベル12.5で1,492 CP、あと0.5上げるとリーグから外れます。ハイパーリーグならレベル20.5で2,447 CPです。

    レイド用にレベル40まで上げたポケモンがスーパーリーグで使えないのは、とっくに上限を超えていて、レベルを下げる手段がないからです。投資する前に、自分が遊ぶリーグで計算してください。

    ポケモンGO CP計算ツールのよくある質問

    CPはどう計算されますか？

    CPは3つの隠し能力とレベルから決まります。種族ごとにこうげき・ぼうぎょ・HPの種族値があり、個体値がそれぞれに0〜15を足し、最後にレベルの倍率の2乗をかけて10で割ります。ゲームは常に切り捨てで、10を下回ることはありません。

    CPが高い＝強い、ですか？

    CPだけでは分かりません。CPはこうげきを重く見るので、攻撃が高くて耐久が低い種族が、CPでは負けているのに勝率で上回ることがあります。同じCPでも個体値の配分は違い、上限のあるPvPではCPが低いほうが良い選択になることもよくあります。

    ポケモンGOの最高CPはいくつですか？

    この計算機が扱う種族では、ケッキングが個体値完璧のレベル50で5,010が最高です。王冠形態まで含めるとさらに上がり、ザシアン（王冠）が5,629、ザマゼンタ（王冠）が5,311です。

    個体値完璧なミュウツーのCPは？

    個体値15/15/15のミュウツーは、レベル40で4,178、レベル50で4,724です。捕獲直後のレベル25では2,984、0/0/0なら2,641。この差が、この種族で個体値が開けられる幅のすべてです。

    レベル40なのにCPが低いのはなぜですか？

    同じ種族・同じレベルで、個体値だけが違う場合です。差が大きいのは耐久型で、ミュウツーはレベル40で3,697〜4,178、個体値だけで481の幅があります。

    スーパーリーグ用にはどこまで強化すべきですか？

    CPが1,500以下になる最大のレベルで止めてください。個体値完璧なミュウツーならレベル12.5で1,492 CP、あと0.5上げると上限を超えてリーグから外れます。

    進化するとCPは変わりますか？

    はい、大きく変わります。進化するとレベルと個体値はそのまま、種族値が新しい種族のものに入れ替わるので、CPはその種族をいまのレベルで計算した値になります。500 CPの御三家が進化しても500のまま、ということはまずありません。

    野生で捕まえられるCPの上限は？

    野生のポケモンはレベル1〜30、天候ブーストが付くと35までで出現します。レイド産はレベル20、天候ブーストで25です。だから捕まえたばかりの伝説でも、個体値完璧なら2,984に近い数字になるわけです。

    個体値とレベル、どちらが大事ですか？

    低いレベルでは、レベルのほうが個体値よりずっとCPを動かします。レベル20から40でCPはほぼ2倍、個体値を完璧にしても8〜10%程度です。個体値が勝敗を分けるのは、2匹のレベルが並んだときだけです。

    CPは4,000を超えますか？

    一部の種族だけです。この計算機のレベル50の表では、個体値完璧で4,000を超える種族が62種いて、最高はケッキングの5,010です。
