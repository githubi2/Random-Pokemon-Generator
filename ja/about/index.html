Random Pokemon Generator について・お問い合わせ

Random Pokemon Generator は非公式のファンプロジェクトです。プレイヤー、配信者、ヌズロック、ドラフトリーグ向けに、ランダム系のポケモンツールを少しずつ増やしてきました。任天堂、ゲームフリーク、株式会社ポケモンとは一切関係ありません。ここではプロジェクトの中身、作り方、連絡先をまとめています。

プロジェクトについて

このサイトについて

ファンが、ファンのために作っています

Random Pokemon Generator は、フィルター付きのランダムポケモン生成とチームレポートという1つのツールから始まりました。そこから少しずつ道具箱になっていきました。新しいツールや改善は、プレイヤーの要望をもとに定期的に出しています。基準は毎回同じで、読み込みが速いこと、データが正確なこと、開いて数秒で役に立つことです。

ポケモンのデータ（名前、タイプ、種族値、とくせい、画像）はオープンな PokeAPI のデータセットから取得しています。サーバーには何も保存しません。フィルター、履歴、共有リンクはすべてあなたのブラウザの中にあります。

あらゆる「ランダム」をそろえて

いまのツール群には、 ヌズロック編成で縛りプレイの進行管理、 パーティ編成でチーム編成、 ポケモンルーレットで一発勝負のドラマチックな抽選がそろっています。さらに、 色違いの出現率 のような深掘りページも加わり、すべてブラウザ内で動いてアカウントは不要です。

生成だけでなく、遊べるページも

遊ぶためだけのページもあります。 Smash or Passで図鑑全体を採点し、 このポケモンだあれ？でシルエット当て、 ランダム名前生成で最高のニックネーム探し。どのツールもブラウザ内で完結し、アカウントも登録も要りません。

リファレンスページと計算ツール

回す系のほかにも、参照用のページを最新に保っています。 タイプ相性表 は324通りの相性すべてを複合タイプの計算機で網羅し、 ポケモン性格表 は25種類のせいかくをポケモン別の推奨付きで並べています。色違い確率の計算ツールはすべての狩り方を順に解説し、 個体値計算 はゲーム内で実際に見える能力値から、隠れた個体値を逆算します。

「ランダム」というテーマから外れたページも、意図的に2つあります。 ランダム選出 はメインのジェネレーターを1回だけ引く版、 ポケモン検索 は名前からポケモンを最短で引く方法です。どれも同じデータセットを読んでいるので、検索したポケモンは、回しても、調整しても、印刷しても同じポケモンです。

中身の話

どう作られているか

あえて地味な技術で

すべてのページは、素の HTML・CSS・JavaScript で手書きしています。フレームワークなし、ビルド工程なし、依存関係なしです。おかげでどの端末でも軽く、監査しやすく、保守も簡単です。プロジェクト全体がオープンソースなので、抽選がどう計算されているか誰でもそのまま読めます。

オープンなデータと、出典の明記

ポケモンのデータ、種族値、公式画像はコミュニティ運営の PokeAPI プロジェクトから取得しています。色違いの確率とゲームの仕様は、ゲーム内の資料とコミュニティの検証をもとにまとめました。確定値ではなく推定値の場合は、ページにそう書いています。

仕様系のページは、いちばん厳しく確認しています。タイプ相性表は第6世代以降の相性を使い、せいかく表は10パーセントの倍率に従い、個体値計算機はゲームと同じ式で動きます。新しい世代でルールが変わったら、影響するページを同じリリースで更新し、変更はプロジェクトのコミット履歴に残します。

気分ではなく、検証できること

このサイトの数字はすべてたどれます。各ツールは参照した PokeAPI の項目を示しており、サイト全体のソースコードは公開されています。数値がおかしいと思ったら、フォーラムに書くより issue を立てたほうが早く直ります。「推定」と正直に書くページのほうが、自信満々に推測するページより良いと思っています。

データはあなたのもの

抽選履歴、保存したチーム、設定はブラウザのローカルストレージにだけ残ります。アカウントがないので、漏れるものもありません。利用状況の集計は、自前の Cookie を使わない Plausible インスタンスと、Google Analytics 4、Microsoft Clarity から取得しています。分析をブロックしても、どのツールも同じように動きます。詳しくは プライバシーポリシーに書いてあります。利用ルールは 利用規約.

連絡先

お問い合わせ

不具合とデータの誤り

メンテナーにいちばん早く届くのは、公開 GitHub リポジトリの issue です。 github.com/githubi2/Random-Pokemon-Generator。ページの URL、期待した動作、実際に起きたことを書いてください。数値の誤り、古い仕様、壊れたフィルターは優先度が高く、たいてい次の更新で直ります。

機能やツールの提案

アイデアも同じ issue ページで歓迎します。出荷済みのツールのいくつかは、プレイヤーの提案から生まれました。いちばん役に立つのは、シチュエーションが分かる要望です。ヌズロックのルールセット、配信の1コーナー、ドラフトリーグの形式、授業での使い方など。サイトの「ランダム系ツール」という軸に合い、オープンなデータで作れるものであれば、ロードマップに載せます。

返信について

本業のかたわらで続けている趣味のプロジェクトなので、返信はすぐではありません。それでも issue にはすべて目を通していますし、公開の issue トラッカーで進み具合が分かります。プライバシーに関わる質問は、プライバシーポリシーにほとんどが平易な言葉で書いてあります。

よくある質問

このサイトについて & お問い合わせFAQ

Random Pokemon Generator は公式のポケモンサイトですか？

いいえ。非公式のファンプロジェクトで、任天堂、ゲームフリーク、株式会社ポケモンとは提携も、承認も、後援も受けていません。ポケモンおよびキャラクター名は各権利者の商標です。

このサイトは誰が運営していますか？

個人の開発者で、長年のポケモンファンが作って維持しています。趣味のプロジェクトで、ツールはすべて素の JavaScript で手書きし、オープンソースで公開し、コミュニティからのプレイヤーの声をもとに改善しています。

不具合や誤ったデータはどう報告すればいいですか？

不具合や数字の誤りを見つけたら、公開 GitHub リポジトリ（github.com/githubi2/Random-Pokemon-Generator、フッターにもリンクがあります）で issue を立ててください。どのページで、何を期待して、実際に何が起きたかを書いてもらえれば助かります。種族値、タイプ、確率の訂正は特にありがたく、たいてい次の更新で反映されます。

新しいツールや機能を提案できますか？

できます。提案は同じ GitHub の issue ページに集まり、出荷済みのツールのいくつかはプレイヤーの要望から始まりました。使い道（ヌズロックの通しプレイ、配信の1コーナー、ドラフトリーグなど）を書いてください。サイトの「ランダム系ツール」という軸で評価します。

スマホでも使えますか？

使えます。どのページもレスポンシブで、小さい画面ではハンバーガーメニューとタッチしやすい操作部品になります。ツールはすべてブラウザ内で動くので、一度読み込めばオフラインでも使えます。アプリのインストールは不要です。

利用に料金はかかりますか？

かかりません。ペイウォールも、サブスクも、有料プランもありません。オープンソースで、公開インフラ上で、趣味として運営しています。有料版を名乗るバッジやツールがあっても、それはこのサイトのものではありません。

ツールを商用利用できますか？

ソースコードはリポジトリに含まれるオープンソースライセンスで公開しているので、クレジットを明記すれば個人利用も商用利用もできます。ただしポケモンの名前と画像は任天堂、ゲームフリーク、株式会社ポケモンの商標なので、そこは別途許諾が必要です。

データは最新作に対応していますか？

対応しています。データセットは第9世代までの全国図鑑を追いかけており、新しいゲームでルールが変われば仕様系のページも改訂します。古い作品の数値が必要な場合も、各ページに出典が書いてあるので、どのバージョンの話かは特定できます。
